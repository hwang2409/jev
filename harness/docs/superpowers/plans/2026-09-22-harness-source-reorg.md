# Harness source reorg implementation plan

## Goal

Reorganize `harness/src/zeta/` without changing harness behavior. Each
registered tool becomes a package. Shared helpers and framework support move
to their owning packages. Tool-private tests move beside their owners.

This plan translates the merged design spec into four independently reviewable
stage PRs. It does not change tool logic, schemas, assertions, provider
behavior, storage formats, public APIs, or browser scope.

## Architecture summary

`zeta.tools` remains the built-in discovery root. `pkgutil.iter_modules` still
finds top-level tool packages, and each discovered package exposes the same
synchronous `register(registry)` contract. `_shared` stays hidden by the
leading underscore rule. `agent_send` remains a support package with its
explicit registration call from `agent.register()`.

The final layout groups agent lifecycle under `zeta.agent`, runtime support
under `zeta.runtime`, user-facing entry points under `zeta.cli`, settings under
`zeta.config`, image helpers under `zeta.media`, model metadata under
`zeta.models`, shared protocol values under `zeta.protocol`, submission code
under `zeta.submission`, and TUI persistence under `zeta.tui`.

## Source of truth and execution

The move table and stage-3 split table live only in the generator below. The
implementation lanes materialize it as `harness/tools/reorg_derive.py` during
stage 0. They run it from the repository root:

```sh
python3 harness/tools/reorg_derive.py . > /tmp/reorg-derive.txt
```

The generator writes no repository files. It parses imports with `ast`,
resolves relative imports to absolute module names, and scans dotted strings in
test files for monkeypatch references. It emits deterministic move order,
final and interim rewrites, post-split targeted tests, gate commands, and the
shim-excluded old-path scan. Generated blocks below are snapshots of one run.

Every generated block has a `generated by reorg_derive.py` marker. Regenerate
it after source-tree changes. Do not hand-edit generated blocks.

## Global constraints

- Preserve tool names, schemas, handler behavior, approval behavior, result
  shapes, registration order, and the synchronous `register(registry)` API.
- Preserve `zeta.tools.<name>` for every tool package.
- Keep `zeta.cli:main` valid through the CLI package move.
- Do not change assertions. Change only file locations, imports, exports, and
  the specified pytest or packaging configuration.
- Run fresh-process import checks. A warm pytest process is not cycle evidence.
- Compare pre-stage and post-stage collection counts, ordered tool names, and
  ordered schemas.
- Workers run only the generated targeted tests. The orchestrator runs the
  full harness suite once per PR.
- Use `uv run --frozen` for pytest commands. Run `uv build` only in stage 3.
- Keep one-way compatibility shims until the generated scan finds no importer.
- Run a subtractive simplification pass over the final diff.

## Stage narratives

### 1. convert registered tools to packages

Move the thirteen registered tool modules into package initializers. Move the
browser adapter and catalog into `tools/browser/`. Preserve discovery order,
module-global patch seams, and the browser adapter/catalog split.

Risk: relative imports change depth when a module becomes a package. The
generated rewrite list includes those changes and all browser importers.
Rollback: revert the stage-1 commit and restore the original tool and browser
paths. No configuration restore is needed.

### 2. move shared helpers and framework support

Install the lazy runtime initializer before moving runtime support. Move the
three helper modules to `_shared`, move agent presets and plan mode under
`zeta.agent`, and move loop setup under `zeta.runtime.tool_setup`.

Risk: eager runtime imports can recreate the existing registry cycle, and an
underscore package can leak into discovery. Keep `_shared/__init__.py` empty,
keep the runtime exports lazy, and use the generated cold-import gate.
Rollback: revert the stage-2 commit, restore the helper and support paths, and
restore the previous runtime initializer. No configuration restore is needed.

def module_for(path: Path) -> str:

def resolve(current: str, level: int, module: str | None) -> str:
    if not level:
        return module or ""
    package = current.rsplit(".", 1)[0]
    base = package.split(".") if package else []
    base = base[: len(base) - level + 1]
    if module:
        base += module.split(".")
    return ".".join(base)

def parse_imports(path: Path) -> list[ImportRecord]:
    text = path.read_text()
    tree = ast.parse(text, filename=str(path))
    current = module_for(path) if path.is_relative_to(SRC) else f"tests.{path.stem}"
    records = []
    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            for alias in node.names:
                records.append(ImportRecord(path, node.lineno, alias.name, alias.name, text.splitlines()[node.lineno-1].strip(), "import"))
        elif isinstance(node, ast.ImportFrom):
            target = resolve(current, node.level, node.module)
            old = ("." * node.level + (node.module or "")) if node.level else target
            records.append(ImportRecord(path, node.lineno, old, target, text.splitlines()[node.lineno-1].strip(), "from"))
    return sorted(records, key=lambda r: (display(r.path), r.line, r.old))


def remap(name: str, moves: list[tuple[str, str]]) -> str:
    for old, new in sorted(moves, key=lambda item: len(item[0]), reverse=True):
        if name == old or name.startswith(old + "."):
            return new + name[len(old):]
    return name


def importer_module(path: Path, moves: list[tuple[str, str]]) -> str:
    if path.is_relative_to(SRC):
        module = remap(module_for(path), moves)
        if module in PACKAGE_ROOTS:
            return module + ".__init__"
        return module
    rel = path.relative_to(HARNESS).with_suffix("")
    return ".".join(rel.parts)


def relative_import(current: str, target: str) -> str:
    package = current.rsplit(".", 1)[0].split(".")
    target_parts = target.split(".")
    common = 0
    while common < min(len(package), len(target_parts)) and package[common] == target_parts[common]:
        common += 1
    level = len(package) - common + 1
    tail = ".".join(target_parts[common:])
    return f"{'.' * level}{tail}"


def import_text(record: ImportRecord, target: str, current: str) -> str:
    if record.kind == "import":
        prefix = record.text.removeprefix("import ").split()[0]
        return record.text.replace(prefix, target, 1)
    dotted = relative_import(current, target) if record.old.startswith(".") else target
    names = record.text.split(" import ", 1)[1] if " import " in record.text else "*"
    return f"from {dotted} import {names}"

def stage4_order(records: list[ImportRecord]) -> tuple[list[str], list[tuple[str, str, str]]]:
    entries = dict(MOVE_TABLE[4])
    names = set(entries)
    order_index = {name: i for i, (name, _) in enumerate(MOVE_TABLE[4])}
    shim_roots = {"zeta.loop", "zeta.settings", "zeta.types"}
    deps = {name: set() for name in names}
    for record in records:
        importer = module_for(record.path) if record.path.is_relative_to(SRC) else ""
        importer_root = next((name for name in names if importer == name or importer.startswith(name + ".")), None)
        target_root = next((name for name in names if record.target == name or record.target.startswith(name + ".")), None)
        if importer_root and target_root and importer_root != target_root and target_root not in shim_roots:
            deps[importer_root].add(target_root)
    order = []
    interim = []
    remaining = {name: set(values) for name, values in deps.items()}
    while len(order) < len(names):
        ready = [name for name in names - set(order) if not (remaining[name] - set(order))]
        if ready:
            name = min(ready, key=order_index.get)
        else:
            # Break a cycle at the earliest table entry. Its later targets use
            # old roots at the importer's new depth until those targets move.
            name = min(names - set(order), key=order_index.get)
            for target in sorted(remaining[name] - set(order), key=order_index.get):
                interim.append((name, target, "cycle: keep old target root until target move"))
            remaining[name].clear()
        order.append(name)
    return order, interim
